这是一个桌面四川麻将（血战到底，换三张）单机版游戏，无任何费用，无需注册/登录，无需联网，无广告，不申请任何权限，不采集任何数据，打开即玩。适合个人随时消遣，顺便练手。

玩家是与三个名曰AI实际上只是DFS以及一系列的算法在打牌，并不是当下大火的AI模型。每局牌的洗牌充分随机且纯粹，不会程序或者人为干扰洗牌的随机性，每个算法玩家和人类玩家一样，都只可以看到自己的牌、各家的副露和桌面的弃牌，无法知道其它玩家的暗手和牌墙里剩余的牌，只能靠明牌推理或估算相关概率。算法玩家之间相互独立，不分享数据。

如果开启“未来碰杠估值”开关，算法在可以碰/杠的情况下，以及摸牌之后准备弃牌时，都会评估未来可能的碰杠情况并给出相应估值，以决定到底要不要碰/杠，摸牌之后到底要打哪张牌，算法的思考路径和选项会更多一点。算法会因此多花一点时间，一般两三秒，长则十几秒都有可能。如果你无法忍受算法的这通无聊计算，就关闭该开关。即便关闭，算法未必会有肉眼可见的水平下降。

当前 V1.0 支持游戏配置。一场牌开始时锁定规则；对配置的修改从下一场开始生效。配置保存在本机浏览器中。

**计分规则**
采用四川麻将（血战到底）规则。记分方式为底分1分，在此基础上叠加番数。如牌型加上胡牌类型一共n番，则可收取2^n分（1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024……），上不封顶。

牌型包括普通屁胡0番，对对胡1番，清一色2番，七对2番，龙七对3番（理解为七对2番+1根1番更直观），每增加1根加1番。在上述通常规则的基础上，再加中张1番、全带幺（带幺九）2番，全幺九3番，全将2番（全部是258），一条龙2番等牌型。全带幺（带幺九）指每组牌均含1或者9，全幺九是指所有的牌不是1就是9，意味着只有龙七对一种牌型。能叠加的牌型番数叠加，如清一色+七对+中张、清一色+一条龙、清一色+对对胡+中张等、清一色+全带幺；不能叠加的牌型取最高番数。全将必定叠加对对胡1番+中张1番。

胡牌方式中，金钩钓、海底捞、海底炮、抢杠、杠上花、杠上炮均加 1 番。默认自摸和门清各加 1 番，可在配置中关闭或调整；默认点杠花由未胡玩家各付。七对天然符合门清条件。

中张、全带幺／全幺九、将一色和一条龙，以及自摸、门清可分别配置。全带幺和全幺九共用开关，后者比前者多 1 番，两者不重复计番。各可选番数可设为 0 至 4 番；全幺九随全带幺番数自动增加 1 番。

天胡、地胡、夹心五、卡二条默认关闭。天胡是庄家换三张、定缺后直接起手胡；先暗杠再补牌胡不算天胡。地胡是闲家本人第一次正常摸牌后直接自摸，且本人此前没有碰杠；其他人的碰杠不影响，首次摸牌后暗杠补牌胡也不算地胡。天地胡可叠加门清，自摸番按配置计算。

夹心五要求只听某花色的 5，并以 4、5、6 顺子的中张胡；卡二条要求只听 2 条，并以 1、2、3 条顺子的中张胡。听牌检查排除四张都在自己暗手中的听张；碰牌、明杠和暗杠中的牌不计入此排除条件。查大叫采用同一口径。

点杠花可选择由所有未胡玩家各付，或由点杠者支付一份，不包赔；两种方式均为自摸，是否另加自摸番由自摸配置决定。连七对、九莲宝灯等牌型暂未支持。

“及时雨”默认关闭。开启后，补杠仅在摸到碰牌的第四张时立即开杠才收杠分；先碰后持有第四张，或摸到第四张后未及时开杠，再补杠不收杠分。直杠、暗杠、抢杠、杠上花、杠上炮和根的规则不受影响。

## 单文件打包

安装 Node.js 18 或更高版本后，在项目目录运行 `npm install` 和 `npm run build:single`。手机适配开发期间，命令生成 `dist/mahjong-mobile-preview.html`，包含游戏代码、样式、34 张牌面图片和音效代码。重新运行会覆盖预览文件，不会覆盖现有的 `dist/mahjong.html`。
